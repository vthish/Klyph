# Klyph - Next-Gen Multi-Platform Video & Audio Downloader

Klyph is a modern, high-performance web application designed to extract and download video and audio from **YouTube, Instagram, TikTok, and Facebook** in user-selected qualities (4K, 1080p, 720p, MP3).

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Modern Glassmorphic Dark UI (Custom CSS)
- **Deployment:** Vercel
